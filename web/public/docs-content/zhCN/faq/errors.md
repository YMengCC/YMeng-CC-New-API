---
title: 常见错误
description: 按状态码整理的常见报错、原因和解决方法。
---

调用失败时，先看 HTTP 状态码和返回的 `message`，再对照下表排查。报错信息会根据请求语言显示为中文或英文。

## 401：密钥问题

| 报错信息                   | 原因                                     | 解决方法                                              |
| -------------------------- | ---------------------------------------- | ----------------------------------------------------- |
| 未提供令牌                 | 请求头里没有携带 API 密钥                | 检查是否设置了 `Authorization: Bearer YOUR_API_KEY`   |
| 无效的令牌 / Invalid token | 密钥不存在、已过期、额度已用完或已被禁用 | 到 [API 密钥](/keys) 页面检查密钥状态，必要时重新创建 |

:::tip
所有与密钥相关的问题都统一提示「无效的令牌」，不会单独提示「已过期」。排查时请逐一检查密钥是否启用、是否过期、密钥额度是否用完。
:::

## 403：权限或余额不足

| 报错信息                         | 原因                                               | 解决方法                                    |
| -------------------------------- | -------------------------------------------------- | ------------------------------------------- |
| 用户额度不足 / 预扣费额度失败    | 账户余额不足以支付本次请求                         | 到 [钱包](/wallet) 充值                     |
| token quota is not enough        | 密钥本身设置的额度已用完                           | 编辑密钥调高额度，或改为无限额度            |
| 订阅额度不足或未配置订阅         | 计费偏好为「仅用会员」，但会员额度已用完或没有会员 | 修改计费偏好，见 [会员套餐](/subscriptions) |
| 该令牌无权访问模型 xxx           | 密钥设置了模型限制，不包含该模型                   | 编辑密钥的「模型限制」，或换用其他密钥      |
| 无权访问 xxx 分组                | 当前账户不能使用该分组                             | 编辑密钥换一个可用分组                      |
| 分组 xxx 已被弃用                | 该分组已停用                                       | 编辑密钥换一个可用分组                      |
| 您的 IP 不在令牌允许访问的列表中 | 密钥设置了 IP 白名单                               | 把当前 IP 加入白名单，或清空白名单          |
| 用户已被封禁                     | 账户被停用                                         | 联系站点管理员                              |

## 400：请求参数有误

| 报错信息                         | 原因                      | 解决方法          |
| -------------------------------- | ------------------------- | ----------------- |
| 未指定模型名称，模型名称不能为空 | 请求体中没有 `model` 字段 | 补充 `model` 参数 |

其他 400 错误通常来自上游对参数的校验，请根据 `message` 调整参数。

## 429：请求过于频繁

| 报错信息                             | 原因                         | 解决方法                                          |
| ------------------------------------ | ---------------------------- | ------------------------------------------------- |
| 您已达到请求数限制                   | 超过了模型的请求频率限制     | 降低请求频率后重试                                |
| 请求次数已达到当前会员套餐的窗口上限 | 超过了会员套餐的请求次数上限 | 等待窗口重置，响应头 `Retry-After` 会给出等待秒数 |
| 并发请求数已达到当前套餐上限         | 同时进行的请求太多           | 减少并发，或升级更高档位的会员套餐                |
| （空响应体）                         | 触发了全站限流               | 按 `Retry-After` 等待后重试                       |

## 503：暂无可用线路

| 报错信息                       | 原因                                             | 解决方法                                                                         |
| ------------------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| 分组 xxx 下模型 xxx 无可用渠道 | 该分组暂时没有能提供这个模型的线路，或模型名写错 | 检查模型名拼写；到 [模型广场](/pricing) 确认该模型在你的分组中可用；或换一个分组 |

## 仍然无法解决？

请记下返回信息中的 **request id**，联系站点管理员并提供该标识，便于快速定位问题。
