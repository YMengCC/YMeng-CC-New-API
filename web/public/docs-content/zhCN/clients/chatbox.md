[ChatBox](https://chatboxai.app) 是一款跨平台的 AI 客户端，支持自定义 OpenAI 兼容 API。

## 准备工作

在 [API 密钥](/keys) 页面创建一个密钥并复制。还没有密钥的话，请先完成 [快速开始](/docs/quick-start) 的前三步。

## 配置步骤

1. 打开 ChatBox，进入 **设置 → 模型**；
2. 添加一个 **自定义 OpenAI 兼容** 的服务商；
3. **API 密钥** 填写你的密钥；
4. **API 地址（API Host）** 填写：

```text
{{BASE_URL}}/v1
```

5. 在模型列表中填写或选择要使用的模型名称，保存后即可开始对话。

:::tip
部分版本的 ChatBox 会自动在地址后补上 `/v1`。如果按上面填写后报 404，请把地址改为 `{{BASE_URL}}` 再试。
:::

## 推荐模型

- `gpt-4o-mini`
- `gpt-4.1`
- `gemini-2.5-flash`

模型名称以 [模型广场](/pricing) 中你所选分组可用的模型为准。

## 常见问题

| 现象                  | 原因                                 | 解决方法                                                |
| --------------------- | ------------------------------------ | ------------------------------------------------------- |
| 401 / Invalid API Key | 密钥复制不完整，或密钥已被禁用、删除 | 在 API 密钥页面重新复制完整密钥，并确认密钥处于启用状态 |
| insufficient quota    | 账户余额或代金券额度已用完           | 到钱包页面充值，或确认所选分组是否支持代金券            |
| 部分网络下连接超时    | 本地网络访问该地址不稳定             | 换一个网络重试，或联系站点管理员确认服务状态            |
