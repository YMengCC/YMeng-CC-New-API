[Cherry Studio](https://cherry-ai.com) 是一款全能型桌面 AI 客户端，原生支持 OpenAI 兼容的服务商。

## 准备工作

在 [API 密钥](/keys) 页面创建一个密钥并复制。还没有密钥的话，请先完成 [快速开始](/docs/quick-start) 的前三步。

## 配置步骤

1. 打开 Cherry Studio，进入 **设置 → 模型服务**；
2. 点击 **添加**，服务商类型选择 **OpenAI**，名称随意填写，例如 `{{SYSTEM_NAME}}`；
3. **API 密钥** 填写你的密钥；
4. **API 地址** 填写：

```text
{{BASE_URL}}/v1
```

5. 点击 **管理** 或 **添加模型**，填入要使用的模型名称；
6. 回到对话界面，在顶部选择刚添加的模型即可开始对话。

:::warning
API 地址要与上面完全一致：不要漏掉或重复 `/v1`，末尾不要多加斜杠。
:::

## 推荐模型

- `gpt-4o-mini`
- `gpt-4.1`
- `claude-sonnet-5`

模型名称以 [模型广场](/pricing) 中你所选分组可用的模型为准。

## 常见问题

| 现象                  | 原因                                 | 解决方法                                                |
| --------------------- | ------------------------------------ | ------------------------------------------------------- |
| 401 / Invalid API Key | 密钥复制不完整，或密钥已被禁用、删除 | 在 API 密钥页面重新复制完整密钥，并确认密钥处于启用状态 |
| model not found       | 模型名与所选分组实际可用的模型不一致 | 从推荐模型中选择，或到模型广场查看可用列表              |
| 请求卡住无响应        | 地址少了或多了 `/v1`，或结尾多了斜杠 | 严格按本页的 API 地址填写                               |
