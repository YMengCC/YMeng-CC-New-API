[Cherry Studio](https://cherry-ai.com) 是一款全能型桌面 AI 用戶端，原生支援 OpenAI 相容的服務商。

## 準備工作

在 [API 金鑰](/keys) 頁面建立一個金鑰並複製。還沒有金鑰的話，請先完成 [快速開始](/docs/quick-start) 的前三步。

## 設定步驟

1. 開啟 Cherry Studio，進入 **設定 → 模型服務**；
2. 點選 **新增**，服務商類型選擇 **OpenAI**，名稱隨意填寫，例如 `{{SYSTEM_NAME}}`；
3. **API 金鑰** 填寫你的金鑰；
4. **API 位址** 填寫：

```text
{{BASE_URL}}/v1
```

5. 點選 **管理** 或 **新增模型**，填入要使用的模型名稱；
6. 回到對話介面，在頂部選擇剛新增的模型即可開始對話。

:::warning
API 位址要與上面完全一致：不要漏掉或重複 `/v1`，結尾不要多加斜線。
:::

## 推薦模型

- `gpt-4o-mini`
- `gpt-4.1`
- `claude-sonnet-5`

模型名稱以 [模型廣場](/pricing) 中你所選分組可用的模型為準。

## 常見問題

| 現象                  | 原因                                   | 解決方法                                                |
| --------------------- | -------------------------------------- | ------------------------------------------------------- |
| 401 / Invalid API Key | 金鑰複製不完整，或金鑰已被停用、刪除   | 在 API 金鑰頁面重新複製完整金鑰，並確認金鑰處於啟用狀態 |
| model not found       | 模型名稱與所選分組實際可用的模型不一致 | 從推薦模型中選擇，或到模型廣場查看可用列表              |
| 請求卡住沒有回應      | 位址少了或多了 `/v1`，或結尾多了斜線   | 嚴格按本頁的 API 位址填寫                               |
