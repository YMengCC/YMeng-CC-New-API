[ChatBox](https://chatboxai.app) 是一款跨平台的 AI 用戶端，支援自訂 OpenAI 相容 API。

## 準備工作

在 [API 金鑰](/keys) 頁面建立一個金鑰並複製。還沒有金鑰的話，請先完成 [快速開始](/docs/quick-start) 的前三步。

## 設定步驟

1. 開啟 ChatBox，進入 **設定 → 模型**；
2. 新增一個 **自訂 OpenAI 相容** 的服務商；
3. **API 金鑰** 填寫你的金鑰；
4. **API 位址（API Host）** 填寫：

```text
{{BASE_URL}}/v1
```

5. 在模型列表中填寫或選擇要使用的模型名稱，儲存後即可開始對話。

:::tip
部分版本的 ChatBox 會自動在位址後補上 `/v1`。如果按上面填寫後出現 404，請把位址改為 `{{BASE_URL}}` 再試。
:::

## 推薦模型

- `gpt-4o-mini`
- `gpt-4.1`
- `gemini-2.5-flash`

模型名稱以 [模型廣場](/pricing) 中你所選分組可用的模型為準。

## 常見問題

| 現象                  | 原因                                 | 解決方法                                                |
| --------------------- | ------------------------------------ | ------------------------------------------------------- |
| 401 / Invalid API Key | 金鑰複製不完整，或金鑰已被停用、刪除 | 在 API 金鑰頁面重新複製完整金鑰，並確認金鑰處於啟用狀態 |
| insufficient quota    | 帳戶餘額或代金券額度已用完           | 到錢包頁面儲值，或確認所選分組是否支援代金券            |
| 部分網路下連線逾時    | 本機網路存取該位址不穩定             | 換一個網路重試，或聯絡站點管理員確認服務狀態            |
