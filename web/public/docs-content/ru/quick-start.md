На этой странице вы с нуля пройдёте весь путь: **регистрация → пополнение → создание ключа API → настройка клиента → первый вызов**. Это займёт всего несколько минут.

:::info Запомните эти два параметра
- **Base URL**: `{{BASE_URL}}/v1` (для OpenAI-совместимых клиентов и SDK)
- **Авторизация**: заголовок запроса `Authorization: Bearer ваш ключ API`
:::

## Шаг 1. Регистрация

Откройте [страницу регистрации](/sign-up), укажите имя пользователя и пароль. Если на сайте доступны другие способы входа — по электронной почте, через GitHub и т. д., — можно воспользоваться ими.

![Страница регистрации](/docs-assets/quick-start/ru/step-1-sign-up.png 'Страница регистрации')

## Шаг 2. Пополнение

После входа нажмите **Баллы** в левом меню, чтобы перейти на [страницу кошелька](/wallet). В разделе «Добавить средства» выберите готовую сумму или введите свою, затем выберите способ оплаты и оплатите. Если у вас есть код активации, его можно активировать на этой же странице.

![Раздел пополнения на странице кошелька](/docs-assets/quick-start/ru/step-2-top-up.png 'Выберите сумму и способ оплаты в разделе «Добавить средства»')

:::tip
Пополненный баланс не сгорает. Доступные суммы, способы оплаты и минимальная сумма пополнения указаны на странице. Правила тарификации описаны в разделе [Тарификация](/pricing).
:::

## Шаг 3. Создание ключа API

Перейдите на страницу [Ключи API](/keys) и нажмите **Создать ключ API** в правом верхнем углу:

1. **Название**: любое, чтобы вам было удобно различать ключи, например `my-first-key`.
2. **Группа**: группа определяет, какие модели может вызывать ключ и по какому множителю идёт тарификация. В выпадающем списке показаны множитель каждой группы и то, поддерживает ли она ваучеры.
3. **Время истечения срока действия** и **Квота**: оставьте значения по умолчанию (бессрочно, без ограничения квоты); настраивайте их, только если нужно ограничить риски.
4. Нажмите **Сохранить изменения**.

![Создание ключа API](/docs-assets/quick-start/ru/step-3-create-key.png 'Укажите название и выберите группу')

:::warning Храните ключ API так же бережно, как пароль
Ключ позволяет напрямую расходовать ваш баланс. Не отправляйте его в групповые чаты, не показывайте на скриншотах и не публикуйте в открытых репозиториях. При утечке сразу отключите или удалите ключ в списке и создайте новый.
:::

## Шаг 4. Настройка клиента

В списке ключей нажмите значок копирования рядом с ключом или откройте меню **⋯** справа и выберите **Копировать ключ**. В этом же меню есть:

- **CC Switch**: импорт ключа в CC Switch в один клик — удобно для пользователей Claude Code.
- **Чат**: открыть ключ сразу в поддерживаемом чат-клиенте.

![Меню действий с ключом](/docs-assets/quick-start/ru/step-4-key-menu.png 'Скопируйте ключ или импортируйте его в клиент в один клик')

Затем укажите в клиенте два параметра:

| Тип клиента                                               | Адрес (Base URL / API Host) | Ключ         |
| --------------------------------------------------------- | --------------------------- | ------------ |
| OpenAI-совместимые клиенты (Cherry Studio, ChatBox и др.) | `{{BASE_URL}}/v1`           | Ваш ключ API |
| Claude Code                                               | `{{BASE_URL}}` (без `/v1`)  | Ваш ключ API |

:::danger Самая частая ошибка — лишний или пропущенный /v1 в адресе
OpenAI-совместимым клиентам обычно нужен `/v1`, а для Claude Code его добавлять **нельзя**. Некоторые клиенты сами дописывают `/v1` — в этом случае укажите только `{{BASE_URL}}`. Не ставьте косую черту в конце адреса. Как заполнять адрес в каждом клиенте, смотрите в разделе [Подключение клиентов](/docs/clients/cherry-studio).
:::

## Шаг 5. Первый вызов

Замените `YOUR_API_KEY` в команде ниже на свой ключ и выполните её в терминале:

```bash
curl {{BASE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{ "role": "user", "content": "Привет, это мой первый вызов" }]
  }'
```

Если в ответе есть поле `choices`, подключение прошло успешно. Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

Если не хотите пользоваться командной строкой, откройте [Песочницу](/playground), выберите модель и отправьте сообщение для проверки.

![Проверка в Песочнице](/docs-assets/quick-start/ru/step-5-playground.png 'Отправьте первое сообщение в Песочнице')
