{{SYSTEM_NAME}} предоставляет по одному адресу сразу три набора интерфейсов — OpenAI-совместимый, нативный Claude (Anthropic) и нативный Gemini; все они вызываются одним и тем же ключом API.

## Base URL

| Протокол           | Base URL              | Примечание                                                |
| ------------------ | --------------------- | --------------------------------------------------------- |
| OpenAI-совместимый | `{{BASE_URL}}/v1`     | Подходит для большинства SDK и клиентов                   |
| Нативный Claude    | `{{BASE_URL}}`        | Anthropic SDK и Claude Code сами добавляют `/v1/messages` |
| Нативный Gemini    | `{{BASE_URL}}/v1beta` | Для Google Gen AI SDK или прямых вызовов                  |

## Авторизация

Все интерфейсы поддерживают передачу ключа в заголовке запроса:

```http
Authorization: Bearer YOUR_API_KEY
```

Некоторые интерфейсы также поддерживают нативный способ, принятый в SDK соответствующих провайдеров:

| Заголовок / параметр                                   | Интерфейсы                                                   |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| `x-api-key: YOUR_API_KEY`                              | Интерфейс Claude `/v1/messages`, список моделей `/v1/models` |
| `x-goog-api-key: YOUR_API_KEY` или `?key=YOUR_API_KEY` | Интерфейс Gemini `/v1beta/models/...`, список моделей        |

:::warning
Храните ключ API только на сервере или в локальной конфигурации. Не встраивайте его во фронтенд-код веб-страниц, мини-приложений и т. п. — иначе любой сможет его увидеть и украсть.
:::

## Ответы с ошибками

При неудачном запросе возвращается код состояния, отличный от 2xx, а тело ответа — JSON. Формат для OpenAI-совместимых интерфейсов:

```json
{
  "error": {
    "code": "",
    "message": "Invalid token (request id: 2026093010545547265...)",
    "type": "new_api_error"
  }
}
```

request id в конце `message` помогает администратору сайта быстро найти проблему — указывайте его при обращении.

Частые коды состояния:

| Код состояния | Значение                                                                                   |
| ------------- | ------------------------------------------------------------------------------------------ |
| 400           | Ошибка в параметрах запроса, например не указано название модели                           |
| 401           | Ключ не передан либо недействителен, истёк или отключён                                    |
| 403           | Недостаточно средств или нет доступа к этой группе / модели                                |
| 429           | Слишком частые запросы, повторите позже (ориентируйтесь на заголовок ответа `Retry-After`) |
| 503           | В этой группе временно нет доступных маршрутов                                             |

Конкретные причины каждой ошибки и способы их устранения описаны в разделе [Частые ошибки](/docs/faq/errors).
