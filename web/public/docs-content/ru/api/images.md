Интерфейс изображений совпадает по формату с OpenAI Images API.

## Генерация изображения

`POST /v1/images/generations`

```bash
curl {{BASE_URL}}/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "Рыжий кот греется на солнце на подоконнике, акварель",
    "size": "1024x1024",
    "n": 1
  }'
```

Основные параметры:

| Параметр          | Описание                                                                             |
| ----------------- | ------------------------------------------------------------------------------------ |
| `model`           | Название модели генерации изображений — см. Витрину моделей                          |
| `prompt`          | Описание изображения                                                                 |
| `size`            | Размер изображения, например `1024x1024`; допустимые значения зависят от модели      |
| `n`               | Количество изображений, не более 128 за запрос; фактический предел зависит от модели |
| `response_format` | `url` или `b64_json`; некоторые модели поддерживают только один из вариантов         |

## Редактирование изображения

`POST /v1/images/edits`

Загрузите исходное изображение и описание в формате `multipart/form-data`:

```bash
curl {{BASE_URL}}/v1/images/edits \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F model="gpt-image-1" \
  -F image="@input.png" \
  -F prompt="Замени фон на закат на морском берегу"
```

## Тарификация

Модели генерации изображений могут тарифицироваться за запрос или по токенам; при генерации нескольких изображений за раз стоимость суммируется по их количеству. Цены смотрите в [Витрине моделей](/pricing), правила тарификации — в разделе [Тарификация](/pricing).

:::tip
Ссылки на изображения, возвращаемые в формате `url`, обычно действуют ограниченное время — изображения, которые нужно хранить долго, скачивайте своевременно.
:::

Названия моделей в тексте приведены только для примера; фактически доступные модели смотрите в [Витрине моделей](/pricing).
