## Список моделей

`GET /v1/models`

Возвращает модели, которые может вызывать текущий ключ API:

```bash
curl {{BASE_URL}}/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Интерфейс автоматически выбирает формат ответа по заголовкам запроса:

| Заголовок запроса                 | Формат ответа    |
| --------------------------------- | ---------------- |
| `Authorization: Bearer ...`       | Формат OpenAI    |
| `x-api-key` + `anthropic-version` | Формат Anthropic |
| `x-goog-api-key` или `?key=`      | Формат Gemini    |

Запрос одной модели: `GET /v1/models/{model}`.

## Цены

`GET /api/pricing`

Возвращает публичные цены всех моделей; этот же интерфейс использует страница [Витрина моделей](/pricing). Ключ API не нужен; если на сайте Витрина моделей доступна только после входа, сначала войдите в систему.

```bash
curl {{BASE_URL}}/api/pricing
```

Основные поля каждой модели в массиве `data`:

| Поле               | Описание                                             |
| ------------------ | ---------------------------------------------------- |
| `model_name`       | Название модели                                      |
| `quota_type`       | Способ тарификации: `0` — по объёму, `1` — за запрос |
| `model_ratio`      | Множитель модели (при тарификации по объёму)         |
| `completion_ratio` | Во сколько раз выходные токены дороже входных        |
| `model_price`      | Цена одного запроса (при тарификации за запрос)      |
| `enable_groups`    | Группы, в которых доступна модель                    |

:::tip
Нагляднее смотреть цены прямо в [Витрине моделей](/pricing): там множители уже пересчитаны в цену за миллион токенов, а список можно фильтровать по группам.
:::
