Если вызов завершился ошибкой, сначала посмотрите код состояния HTTP и возвращённое `message`, затем найдите их в таблицах ниже. В зависимости от языка запроса сообщения об ошибках выводятся на китайском или английском.

## 401. Проблемы с ключом

| Сообщение об ошибке | Причина                                                        | Решение                                                                                     |
| ------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Token not provided  | В заголовке запроса не передан ключ API                        | Проверьте, задан ли заголовок `Authorization: Bearer YOUR_API_KEY`                          |
| Invalid token       | Ключ не существует, истёк, его квота исчерпана или он отключён | Проверьте состояние ключа на странице [Ключи API](/keys) и при необходимости создайте новый |

:::tip
Для всех проблем, связанных с ключом, выводится одно и то же сообщение «Invalid token» — отдельного сообщения «истёк» нет. При поиске причины последовательно проверьте, включён ли ключ, не истёк ли он и не исчерпана ли его квота.
:::

## 403. Нет доступа или недостаточно средств

| Сообщение об ошибке                                                                                | Причина                                                                                     | Решение                                                             |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 用户额度不足 / 预扣费额度失败 (недостаточно квоты пользователя / не удалось зарезервировать квоту) | На балансе счёта недостаточно средств для оплаты запроса                                    | Пополните счёт в [Кошельке](/wallet)                                |
| token quota is not enough                                                                          | Исчерпана квота, заданная для самого ключа                                                  | Отредактируйте ключ, увеличив квоту или сняв ограничение            |
| 订阅额度不足或未配置订阅 (недостаточно квоты подписки или подписка не настроена)                   | Выбрано предпочтение оплаты «Только членство», но квота членства исчерпана или членства нет | Измените предпочтение оплаты, см. [Тарифы членства](/subscriptions) |
| This token has no access to model xxx                                                              | Для ключа заданы лимиты моделей, и эта модель в них не входит                               | Отредактируйте «Лимиты модели» ключа или используйте другой ключ    |
| 无权访问 xxx 分组 (нет доступа к группе xxx)                                                       | Текущему аккаунту недоступна эта группа                                                     | Отредактируйте ключ и выберите доступную группу                     |
| 分组 xxx 已被弃用 (группа xxx выведена из использования)                                           | Группа отключена                                                                            | Отредактируйте ключ и выберите доступную группу                     |
| 您的 IP 不在令牌允许访问的列表中 (ваш IP-адрес не входит в список разрешённых для токена)          | Для ключа задан белый список IP-адресов                                                     | Добавьте текущий IP в белый список или очистите его                 |
| User has been banned                                                                               | Аккаунт заблокирован                                                                        | Свяжитесь с администратором сайта                                   |

## 400. Ошибка в параметрах запроса

| Сообщение об ошибке                                  | Причина                         | Решение                   |
| ---------------------------------------------------- | ------------------------------- | ------------------------- |
| Model name not specified, model name cannot be empty | В теле запроса нет поля `model` | Добавьте параметр `model` |

Прочие ошибки 400 обычно возникают при проверке параметров на стороне вышестоящего провайдера — исправьте параметры согласно `message`.

## 429. Слишком частые запросы

| Сообщение об ошибке                                                                             | Причина                                       | Решение                                                                            |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------- |
| You have reached the request limit                                                              | Превышен лимит частоты запросов к модели      | Снизьте частоту запросов и повторите попытку                                       |
| 请求次数已达到当前会员套餐的窗口上限 (достигнут лимит запросов в окне текущего тарифа членства) | Превышен лимит числа запросов тарифа членства | Дождитесь сброса окна; заголовок ответа `Retry-After` укажет, сколько секунд ждать |
| 并发请求数已达到当前套餐上限 (достигнут лимит одновременных запросов текущего тарифа)           | Слишком много одновременных запросов          | Уменьшите параллелизм или перейдите на тариф членства более высокого уровня        |
| (пустое тело ответа)                                                                            | Сработало ограничение частоты для всего сайта | Подождите время, указанное в `Retry-After`, и повторите попытку                    |

## 503. Нет доступных маршрутов

| Сообщение об ошибке                                | Причина                                                                                               | Решение                                                                                                                                      |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| No available channel for model xxx under group xxx | В этой группе временно нет маршрута, обслуживающего эту модель, или название модели указано с ошибкой | Проверьте написание названия модели; убедитесь в [Витрине моделей](/pricing), что модель доступна в вашей группе; или выберите другую группу |

## Проблема не решена?

Сохраните **request id** из ответа и свяжитесь с администратором сайта — по нему можно быстро найти причину.
