[Codex CLI](https://github.com/openai/codex) — официальный консольный помощник для программирования от OpenAI. Достаточно задать две переменные окружения, чтобы он вызывал модели через {{SYSTEM_NAME}}.

## Подготовка

Создайте ключ на странице [Ключи API](/keys) и скопируйте его, затем установите Codex CLI по официальной инструкции.

## Настройка

Задайте в терминале следующие переменные окружения (замените `YOUR_API_KEY` на свой ключ).

macOS / Linux:

```bash
export OPENAI_BASE_URL="{{BASE_URL}}/v1"
export OPENAI_API_KEY="YOUR_API_KEY"
```

Windows PowerShell:

```powershell
$env:OPENAI_BASE_URL = "{{BASE_URL}}/v1"
$env:OPENAI_API_KEY = "YOUR_API_KEY"
```

После этого запустите Codex CLI **в том же окне терминала**.

Если вы управляете настройками через [CC Switch](https://ccswitch.io/zh/), можно также открыть меню **⋯** в списке ключей API, выбрать **CC Switch**, указать `Codex` в поле **Приложение** и импортировать настройки в один клик — `/v1` будет добавлен к адресу автоматически.

:::tip Чтобы настройки действовали постоянно
Добавьте приведённые выше команды `export` в файл настроек оболочки, например `~/.bashrc` или `~/.zshrc`, и откройте новый терминал.
:::

## Рекомендуемые модели

- `gpt-4.1`
- `gpt-4o-mini`

Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

## Частые проблемы

| Симптом                                         | Причина                                                                           | Решение                                                                                                                    |
| ----------------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 401                                             | В текущем терминале не задана `OPENAI_API_KEY`                                    | Задайте переменную в том же окне терминала или добавьте её в файл настроек оболочки и откройте новый терминал              |
| Запросы по-прежнему уходят в официальный OpenAI | `OPENAI_BASE_URL` не применилась или перезаписана другими настройками             | Выполните `echo $OPENAI_BASE_URL`, чтобы проверить значение, и найдите конфликтующие настройки в скриптах запуска оболочки |
| model not found                                 | Название модели не совпадает с моделями, фактически доступными в выбранной группе | Выберите модель из рекомендуемых или проверьте список доступных в Витрине моделей                                          |
