[ChatBox](https://chatboxai.app) — кроссплатформенный AI-клиент с поддержкой пользовательских OpenAI-совместимых API.

## Подготовка

Создайте ключ на странице [Ключи API](/keys) и скопируйте его. Если ключа ещё нет, сначала выполните первые три шага из раздела [Быстрый старт](/docs/quick-start).

## Настройка

1. Откройте ChatBox и перейдите в **Настройки → Модель**;
2. Добавьте провайдера типа **Пользовательский OpenAI-совместимый**;
3. В поле **API-ключ** укажите свой ключ;
4. В поле **API-адрес (API Host)** укажите:

```text
{{BASE_URL}}/v1
```

5. Введите или выберите в списке моделей нужное название модели и сохраните — можно начинать общение.

:::tip
Некоторые версии ChatBox автоматически дописывают `/v1` к адресу. Если с указанным выше адресом появляется ошибка 404, измените адрес на `{{BASE_URL}}` и попробуйте снова.
:::

## Рекомендуемые модели

- `gpt-4o-mini`
- `gpt-4.1`
- `gemini-2.5-flash`

Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

## Частые проблемы

| Симптом                              | Причина                                           | Решение                                                                                        |
| ------------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 401 / Invalid API Key                | Ключ скопирован не полностью, отключён или удалён | Заново скопируйте ключ целиком на странице Ключи API и убедитесь, что он включён               |
| insufficient quota                   | Закончились баланс счёта или квота ваучеров       | Пополните счёт на странице кошелька или проверьте, поддерживает ли выбранная группа ваучеры    |
| Таймаут соединения в некоторых сетях | Доступ к адресу из вашей сети нестабилен          | Попробуйте другую сеть или свяжитесь с администратором сайта, чтобы уточнить состояние сервиса |
