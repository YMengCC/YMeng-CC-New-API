[Cursor](https://cursor.com) — IDE для программирования с AI. Встроенные настройки Cursor ограниченно поддерживают пользовательские OpenAI-совместимые адреса, поэтому для подключения рекомендуем открытый инструмент [cursor-byokcx](https://github.com/leookun/cursor-byokcx).

## Подготовка

1. Создайте ключ на странице [Ключи API](/keys) и скопируйте его;
2. Установите cursor-byokcx по инструкции на странице проекта.

## Настройка

1. В cursor-byokcx задайте **API Base URL**:

```text
{{BASE_URL}}/v1
```

2. В поле **API Key** укажите свой ключ;
3. Направьте и **модель для диалога**, и **модель для автодополнения** на этот пользовательский адрес и укажите названия нужных моделей;
4. Сохраните настройки и **перезапустите Cursor**.

:::warning
В Cursor диалог и автодополнение настраиваются отдельно. Если изменить только одну из настроек, возникнет ситуация «автодополнение работает, а диалог выдаёт ошибку».
:::

## Рекомендуемые модели

- `gpt-4.1`
- `claude-sonnet-5`
- `gpt-4o-mini`

Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

## Частые проблемы

| Симптом                                         | Причина                                                                        | Решение                                                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| В списке моделей нет пользовательских моделей   | Инструмент-посредник не установлен или не включён либо Cursor не перезапущен   | Завершите настройку cursor-byokcx, перезапустите Cursor и проверьте снова                             |
| 401 / Invalid API Key                           | Ключ скопирован не полностью, отключён или удалён                              | Заново скопируйте ключ целиком на странице Ключи API и убедитесь, что он включён                      |
| Автодополнение работает, а диалог выдаёт ошибку | Диалог и автодополнение настраиваются отдельно, изменена только одна настройка | В cursor-byokcx направьте и модель для диалога, и модель для автодополнения на пользовательский адрес |
