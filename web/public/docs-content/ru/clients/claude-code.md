[Claude Code](https://docs.anthropic.com/en/docs/claude-code) — официальный консольный помощник для программирования от Anthropic. Подключить его можно двумя способами: импортом в CC Switch в один клик или вручную через переменные окружения.

## Способ 1. Импорт в один клик через CC Switch (рекомендуется)

[CC Switch](https://ccswitch.io/zh/) — инструмент с графическим интерфейсом, который позволяет хранить несколько наборов настроек Claude Code и быстро переключаться между ними.

1. Установите CC Switch;
2. На странице [Ключи API](/keys) откройте меню **⋯** справа от ключа и выберите **CC Switch**;
3. В открывшемся окне выберите `Claude` в поле **Приложение** и укажите **Основную модель** (при желании — модели для Haiku / Sonnet / Opus);
4. Нажмите **Открыть CC Switch**, подтвердите импорт в CC Switch и включите этот набор настроек;
5. Перезапустите терминал и запустите Claude Code.

## Способ 2. Ручная настройка переменных окружения

Задайте в терминале следующие переменные окружения (замените `YOUR_API_KEY` на свой ключ).

macOS / Linux:

```bash
export ANTHROPIC_BASE_URL="{{BASE_URL}}"
export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "{{BASE_URL}}"
$env:ANTHROPIC_AUTH_TOKEN = "YOUR_API_KEY"
```

После этого выполните `claude` в том же окне терминала.

:::danger Не добавляйте /v1 к адресу
Claude Code сам добавляет `/v1/messages`. В `ANTHROPIC_BASE_URL` укажите только `{{BASE_URL}}` — с `/v1` запросы будут завершаться ошибкой.
:::

## Рекомендуемые модели

- `claude-sonnet-5`
- `claude-opus-5`

Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

## Частые проблемы

| Симптом                                               | Причина                                                                                     | Решение                                                                                         |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 401 / authentication_error                            | Не задана `ANTHROPIC_AUTH_TOKEN` либо ключ отключён или удалён                              | Создайте ключ заново и убедитесь, что переменная задана в текущем терминале                     |
| Запросы по-прежнему уходят в официальный Anthropic    | `ANTHROPIC_BASE_URL` не применилась или к ней добавлен `/v1`                                | Укажите адрес строго как на этой странице, без каких-либо путей                                 |
| После смены настроек подключение идёт на старый адрес | Локально перемешались несколько наборов настроек, переключение выполнено не через CC Switch | Управляйте всеми наборами настроек через CC Switch и после переключения перезапускайте терминал |
