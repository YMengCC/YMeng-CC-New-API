[Cherry Studio](https://cherry-ai.com) — универсальный десктопный AI-клиент со встроенной поддержкой OpenAI-совместимых провайдеров.

## Подготовка

Создайте ключ на странице [Ключи API](/keys) и скопируйте его. Если ключа ещё нет, сначала выполните первые три шага из раздела [Быстрый старт](/docs/quick-start).

## Настройка

1. Откройте Cherry Studio и перейдите в **Настройки → Модели**;
2. Нажмите **Добавить**, выберите тип провайдера **OpenAI** и укажите любое название, например `{{SYSTEM_NAME}}`;
3. В поле **API-ключ** укажите свой ключ;
4. В поле **API-адрес** укажите:

```text
{{BASE_URL}}/v1
```

5. Нажмите **Управление** или **Добавить модель** и введите названия нужных моделей;
6. Вернитесь в окно диалога, выберите вверху добавленную модель — и можно начинать общение.

:::warning
API-адрес должен в точности совпадать с указанным выше: не пропускайте и не дублируйте `/v1`, не ставьте косую черту в конце.
:::

## Рекомендуемые модели

- `gpt-4o-mini`
- `gpt-4.1`
- `claude-sonnet-5`

Названия моделей сверяйте с моделями, доступными для выбранной группы в [Витрине моделей](/pricing).

## Частые проблемы

| Симптом                    | Причина                                                                           | Решение                                                                           |
| -------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 401 / Invalid API Key      | Ключ скопирован не полностью, отключён или удалён                                 | Заново скопируйте ключ целиком на странице Ключи API и убедитесь, что он включён  |
| model not found            | Название модели не совпадает с моделями, фактически доступными в выбранной группе | Выберите модель из рекомендуемых или проверьте список доступных в Витрине моделей |
| Запрос зависает без ответа | В адресе пропущен или продублирован `/v1` либо в конце стоит лишняя косая черта   | Укажите API-адрес строго как на этой странице                                     |
