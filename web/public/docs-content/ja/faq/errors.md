---
title: よくあるエラー
description: ステータスコード別に整理した、よくあるエラーとその原因・解決方法。
---

呼び出しが失敗した場合は、まず HTTP ステータスコードと返された `message` を確認し、下の表と照らし合わせて原因を調べてください。エラーメッセージは、リクエストの言語に応じて中国語または英語で表示されます。

## 401：キーの問題

| エラーメッセージ   | 原因                                                                     | 解決方法                                                                      |
| ------------------ | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Token not provided | リクエストヘッダーにAPIキーが含まれていない                              | `Authorization: Bearer YOUR_API_KEY` が設定されているか確認してください       |
| Invalid token      | キーが存在しない、期限切れ、クォータを使い切った、または無効化されている | [APIキー](/keys) ページでキーの状態を確認し、必要に応じて作成し直してください |

:::tip
キーに関する問題はすべて「Invalid token」と表示され、「期限切れ」などが個別に表示されることはありません。原因を調べる際は、キーが有効か、期限切れでないか、キーのクォータを使い切っていないかを一つずつ確認してください。
:::

## 403：権限または残高の不足

| エラーメッセージ                                                                                 | 原因                                                                                                             | 解決方法                                                                        |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 用户额度不足 / 预扣费额度失败（ユーザーのクォータ不足 / 事前課金の仮押さえに失敗）               | アカウント残高が今回のリクエストの支払いに足りない                                                               | [ウォレット](/wallet) でチャージしてください                                    |
| token quota is not enough                                                                        | キー自体に設定されたクォータを使い切った                                                                         | キーを編集してクォータを増やすか、無制限に変更してください                      |
| 订阅额度不足或未配置订阅（サブスクリプションのクォータ不足、またはサブスクリプション未設定）     | 課金の優先設定が「メンバーシップのみ」になっているが、メンバーシップクォータを使い切ったか、メンバーシップがない | 課金の優先設定を変更してください。[メンバーシッププラン](/subscriptions) を参照 |
| This token has no access to model xxx                                                            | キーにモデル制限が設定されており、そのモデルが含まれていない                                                     | キーの「モデル制限」を編集するか、別のキーを使用してください                    |
| 无权访问 xxx 分组（xxx グループへのアクセス権限がありません）                                    | 現在のアカウントではそのグループを使用できない                                                                   | キーを編集して利用可能なグループに変更してください                              |
| 分组 xxx 已被弃用（グループ xxx は廃止されました）                                               | そのグループは停止されている                                                                                     | キーを編集して利用可能なグループに変更してください                              |
| 您的 IP 不在令牌允许访问的列表中（お使いの IP はトークンのアクセス許可リストに含まれていません） | キーに IP ホワイトリストが設定されている                                                                         | 現在の IP をホワイトリストに追加するか、ホワイトリストを空にしてください        |
| User has been banned                                                                             | アカウントが停止されている                                                                                       | サイト管理者にお問い合わせください                                              |

## 400：リクエストパラメーターの誤り

| エラーメッセージ                                     | 原因                                        | 解決方法                               |
| ---------------------------------------------------- | ------------------------------------------- | -------------------------------------- |
| Model name not specified, model name cannot be empty | リクエストボディに `model` フィールドがない | `model` パラメーターを追加してください |

その他の 400 エラーは通常、上流によるパラメーター検証から返されます。`message` の内容に従ってパラメーターを調整してください。

## 429：リクエストが多すぎる

| エラーメッセージ                                                                                             | 原因                                               | 解決方法                                                                                      |
| ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| You have reached the request limit                                                                           | モデルのリクエスト頻度制限を超えた                 | リクエスト頻度を下げてから再試行してください                                                  |
| 请求次数已达到当前会员套餐的窗口上限（リクエスト数が現在のメンバーシッププランのウィンドウ上限に達しました） | メンバーシッププランのリクエスト回数の上限を超えた | ウィンドウのリセットを待ってください。レスポンスヘッダー `Retry-After` に待機秒数が示されます |
| 并发请求数已达到当前套餐上限（同時リクエスト数が現在のプランの上限に達しました）                             | 同時に実行中のリクエストが多すぎる                 | 同時実行数を減らすか、上位のメンバーシッププランにアップグレードしてください                  |
| （空のレスポンスボディ）                                                                                     | サイト全体のレート制限に達した                     | `Retry-After` に従って待ってから再試行してください                                            |

## 503：利用可能な回線がない

| エラーメッセージ                                   | 原因                                                                     | 解決方法                                                                                                                              |
| -------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| No available channel for model xxx under group xxx | そのグループに現在このモデルを提供できる回線がない、またはモデル名の誤り | モデル名のスペルを確認し、[モデル広場](/pricing) でそのモデルがあなたのグループで利用可能か確認するか、別のグループに変更してください |

## それでも解決しない場合

返された情報に含まれる **request id** を控えて、サイト管理者にお問い合わせください。それをもとに問題を迅速に特定できます。
