## 残高に有効期限はありますか？

チャージや引き換えで得た残高に有効期限はありません。クーポンとメンバーシップクォータには有効期限がある場合があり、それぞれの説明に従います。詳しくは [チャージとクーポン](/wallet) をご覧ください。

## 残高の減少額が利用履歴の金額より少ないのはなぜですか？

利用履歴には、各リクエストの**全額の料金**が記録されます。そのリクエストの一部がクーポンで差し引かれた場合、残高からは残りの分だけが差し引かれるため、両者に差が出ます。これは正常な動作です。

## グループはどう選べばよいですか？

グループによって、呼び出せるモデルと課金の倍率が決まります。キー作成時のグループのドロップダウンには、各グループの倍率、メンバーシップ割引後の倍率、クーポン対応の有無が表示されます。一般的には次のように選びます。

- 特定のモデルを使いたい場合：まず [モデル広場](/pricing) で、そのモデルがどのグループで利用できるか確認します。
- クーポンを使いたい場合：「クーポン対応」と表示されたグループを選びます。
- 費用を抑えたい場合：利用可能なグループの中から倍率の低いものを選びます。

## どのモデルに対応していますか？

利用可能なすべてのモデルとその価格は [モデル広場](/pricing) に一覧表示されており、[モデル一覧インターフェース](/docs/api/models-and-pricing) から取得することもできます。モデルは継続的に更新されます。

## 1 つのアカウントで複数のキーを作成できますか？

できます。用途ごとにキーを分けて作成することをおすすめします。例えば Claude Code 用に 1 つ、自分のアプリケーション用に 1 つと分けておくと、使用量の確認、上限設定、停止を個別に行えます。

## キーが漏えいした場合はどうすればよいですか？

ただちに [APIキー](/keys) ページでそのキーを無効化または削除し、新しいキーを作成し直してください。[利用履歴](/usage-logs/common) で不審な呼び出しがないか確認できます。

## 各呼び出しにいくらかかったかを確認するには？

[利用履歴](/usage-logs/common) を開くと、各リクエストの時刻、モデル、token 数、課金額を確認できます。

## リクエストが遅い、またはタイムアウトする場合は？

1. まず [プレイグラウンド](/playground) で同じモデルをテストし、モデル自体の応答が遅いのかを確認します。
2. ローカルネットワークを確認し、別のネットワークを試します。
3. 別のグループに変更します。グループごとに回線が異なります。
4. それでも解決しない場合は、サイト管理者に request id を添えてお問い合わせください。

## どこでサポートを受けられますか？

- [よくあるエラー](/docs/faq/errors) を見て、ご自身で原因を調べられます。
- サイト管理者にお問い合わせください。その際はサイト内のユーザー ID をお知らせください。
