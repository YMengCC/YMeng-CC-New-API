このページでは、ゼロから一連の流れを最後までご案内します。**登録 → チャージ → APIキーの作成 → クライアントの設定 → 最初の呼び出し**。所要時間は数分です。

:::info まずこの 2 点を押さえましょう
- **Base URL**：`{{BASE_URL}}/v1`（OpenAI 互換のクライアントや SDK で使用）
- **認証方式**：リクエストヘッダー `Authorization: Bearer あなたのAPIキー`
:::

## ステップ 1：アカウントを登録する

[登録ページ](/sign-up) を開き、ユーザー名とパスワードを入力して登録を完了します。サイトでメールアドレスや GitHub などの他のログイン方法が有効になっている場合は、それらを利用することもできます。

![登録ページ](/docs-assets/quick-start/ja/step-1-sign-up.png '登録ページ')

## ステップ 2：チャージする

ログイン後、左側メニューの **ポイント** をクリックして [ウォレットページ](/wallet) に移動します。「残高チャージ」エリアでプリセット金額を選ぶかカスタム金額を入力し、チャージ方法を選んで支払いを完了します。引き換えコードをお持ちの場合は、同じページで引き換えることもできます。

![ウォレットページのチャージエリア](/docs-assets/quick-start/ja/step-2-top-up.png '「残高チャージ」で金額とチャージ方法を選択')

:::tip
チャージした残高に有効期限はありません。具体的な金額の選択肢、チャージ方法、最低チャージ金額はページの表示に従ってください。料金ルールは [料金について](/pricing) をご覧ください。
:::

## ステップ 3：APIキーを作成する

[APIキー](/keys) ページを開き、右上の **APIキーを作成** をクリックします。

1. **名称**：用途を区別しやすいよう自由に入力します。例：`my-first-key`。
2. **グループ**：グループによって、このキーで呼び出せるモデルと、課金の倍率が決まります。ドロップダウンには各グループの倍率とクーポン対応の有無が表示されます。
3. **有効期限**、**クォータ**：デフォルトのまま（無期限・無制限）で問題ありません。リスクを管理したい場合に必要に応じて設定してください。
4. **変更を保存** をクリックします。

![APIキーを作成](/docs-assets/quick-start/ja/step-3-create-key.png '名称を入力してグループを選択')

:::warning APIキーはパスワードと同じように大切に管理してください
キーを使えばあなたの残高を直接消費できます。グループチャット、スクリーンショット、公開コードリポジトリには載せないでください。万一漏えいした場合は、ただちに一覧でそのキーを無効化または削除し、新しく作成し直してください。
:::

## ステップ 4：クライアントを設定する

キー一覧でキーの横にあるコピーアイコンをクリックするか、右側の **⋯** メニューから **キーをコピー** を選びます。同じメニューには次の項目もあります。

- **CC Switch**：キーをワンクリックで CC Switch に取り込みます。Claude Code ユーザーにおすすめです。
- **チャット**：対応済みのチャットクライアントで直接開きます。

![キーの操作メニュー](/docs-assets/quick-start/ja/step-4-key-menu.png 'キーをコピー、またはワンクリックでクライアントに取り込み')

次に、クライアントで 2 つの項目を入力します。

| クライアントの種類                                     | アドレス（Base URL / API Host）    | キー            |
| ------------------------------------------------------ | ---------------------------------- | --------------- |
| OpenAI 互換クライアント（Cherry Studio、ChatBox など） | `{{BASE_URL}}/v1`                  | あなたのAPIキー |
| Claude Code                                            | `{{BASE_URL}}`（`/v1` は付けない） | あなたのAPIキー |

:::danger 最も多いミス：アドレスの /v1 の付けすぎ・付け忘れ
OpenAI 互換クライアントでは通常 `/v1` が必要ですが、Claude Code では `/v1` を**付けてはいけません**。クライアントによっては `/v1` を自動で補うものがあり、その場合は `{{BASE_URL}}` だけを入力してください。アドレスの末尾に余分なスラッシュを付けないでください。各クライアントの具体的な設定方法は [クライアント設定](/docs/clients/cherry-studio) をご覧ください。
:::

## ステップ 5：最初の呼び出しを行う

以下のコマンドの `YOUR_API_KEY` をあなたのキーに置き換えて、ターミナルで実行します。

```bash
curl {{BASE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{ "role": "user", "content": "こんにちは、これは初めての呼び出しです" }]
  }'
```

レスポンスに `choices` フィールドが含まれていれば、接続は成功です。モデル名は、[モデル広場](/pricing) で選択したグループで利用できるモデルに従ってください。

コマンドラインを使いたくない場合は、[プレイグラウンド](/playground) を開き、モデルを選んでそのままメッセージを送信してテストできます。

![プレイグラウンドでテスト](/docs-assets/quick-start/ja/step-5-playground.png 'プレイグラウンドで最初のメッセージを送信')
