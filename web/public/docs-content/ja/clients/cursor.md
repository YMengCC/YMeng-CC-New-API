[Cursor](https://cursor.com) は AI プログラミング IDE です。標準の設定ではカスタムの OpenAI 互換アドレスへの対応が限られているため、オープンソースツール [cursor-byokcx](https://github.com/leookun/cursor-byokcx) を利用した接続をおすすめします。

## 事前準備

1. [APIキー](/keys) ページでキーを作成してコピーします。
2. cursor-byokcx プロジェクトページの説明に従ってインストールを完了します。

## 設定手順

1. cursor-byokcx で **API Base URL** を次のように設定します。

```text
{{BASE_URL}}/v1
```

2. **API Key** にあなたのキーを入力します。
3. **対話モデル** と **補完モデル** の両方をこのカスタムアドレスに向け、使用するモデル名を入力します。
4. 設定を保存したら **Cursor を再起動** します。

:::warning
Cursor の対話と補完は、それぞれ独立した 2 つのモデル設定です。片方だけを変更すると、「補完は使えるが対話でエラーになる」という状況が発生します。
:::

## おすすめモデル

- `gpt-4.1`
- `claude-sonnet-5`
- `gpt-4o-mini`

モデル名は、[モデル広場](/pricing) で選択したグループで利用できるモデルに従ってください。

## よくある問題

| 症状                                     | 原因                                                                                     | 解決方法                                                                              |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| モデル一覧にカスタムモデルが表示されない | ブリッジツールがインストールまたは有効化されていない、あるいは Cursor を再起動していない | cursor-byokcx の設定を完了し、Cursor を再起動してから再度確認してください             |
| 401 / Invalid API Key                    | キーのコピーが不完全、またはキーが無効化・削除されている                                 | APIキーページで完全なキーをコピーし直し、キーが有効になっていることを確認してください |
| 補完は使えるが対話でエラーになる         | 対話と補完は別々の設定で、片方しか変更していない                                         | cursor-byokcx で対話モデルと補完モデルの両方をカスタムアドレスに向けてください        |

## 今すぐ試す

キーとモデルが使えるかどうかを先に確認したい場合は、[プレイグラウンド](/playground) でそのままメッセージを送信してみてください。
