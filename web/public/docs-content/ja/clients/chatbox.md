[ChatBox](https://chatboxai.app) はクロスプラットフォームの AI クライアントで、カスタムの OpenAI 互換 API をサポートしています。

## 事前準備

[APIキー](/keys) ページでキーを作成してコピーします。まだキーをお持ちでない場合は、先に [クイックスタート](/docs/quick-start) の最初の 3 ステップを完了してください。

## 設定手順

1. ChatBox を開き、**設定 → モデル** に移動します。
2. **カスタム OpenAI 互換** のプロバイダーを追加します。
3. **API キー** にあなたのキーを入力します。
4. **API アドレス（API Host）** に次を入力します。

```text
{{BASE_URL}}/v1
```

5. モデル一覧で使用するモデル名を入力または選択し、保存すれば対話を始められます。

:::tip
ChatBox のバージョンによっては、アドレスの後ろに `/v1` が自動で補われます。上記のとおり入力して 404 エラーになる場合は、アドレスを `{{BASE_URL}}` に変更して再度お試しください。
:::

## おすすめモデル

- `gpt-4o-mini`
- `gpt-4.1`
- `gemini-2.5-flash`

モデル名は、[モデル広場](/pricing) で選択したグループで利用できるモデルに従ってください。

## よくある問題

| 症状                                       | 原因                                                     | 解決方法                                                                                     |
| ------------------------------------------ | -------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 401 / Invalid API Key                      | キーのコピーが不完全、またはキーが無効化・削除されている | APIキーページで完全なキーをコピーし直し、キーが有効になっていることを確認してください        |
| insufficient quota                         | アカウント残高またはクーポンの額を使い切っている         | ウォレットページでチャージするか、選択したグループがクーポンに対応しているか確認してください |
| 一部のネットワークで接続がタイムアウトする | ローカルネットワークからこのアドレスへのアクセスが不安定 | 別のネットワークで再試行するか、サイト管理者にサービス状況を確認してください                 |

## 今すぐ試す

キーとモデルが使えるかどうかを先に確認したい場合は、[プレイグラウンド](/playground) でそのままメッセージを送信してみてください。
