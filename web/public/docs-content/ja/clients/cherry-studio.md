[Cherry Studio](https://cherry-ai.com) は多機能なデスクトップ AI クライアントで、OpenAI 互換のプロバイダーをネイティブにサポートしています。

## 事前準備

[APIキー](/keys) ページでキーを作成してコピーします。まだキーをお持ちでない場合は、先に [クイックスタート](/docs/quick-start) の最初の 3 ステップを完了してください。

## 設定手順

1. Cherry Studio を開き、**設定 → モデルサービス** に移動します。
2. **追加** をクリックし、プロバイダーの種類で **OpenAI** を選択します。名前は自由に入力できます（例：`{{SYSTEM_NAME}}`）。
3. **API キー** にあなたのキーを入力します。
4. **API アドレス** に次を入力します。

```text
{{BASE_URL}}/v1
```

5. **管理** または **モデルを追加** をクリックし、使用するモデル名を入力します。
6. 対話画面に戻り、上部で追加したモデルを選択すれば対話を始められます。

:::warning
API アドレスは上記と完全に一致させてください。`/v1` の付け忘れや重複に注意し、末尾に余分なスラッシュを付けないでください。
:::

## おすすめモデル

- `gpt-4o-mini`
- `gpt-4.1`
- `claude-sonnet-5`

モデル名は、[モデル広場](/pricing) で選択したグループで利用できるモデルに従ってください。

## よくある問題

| 症状                               | 原因                                                                            | 解決方法                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 401 / Invalid API Key              | キーのコピーが不完全、またはキーが無効化・削除されている                        | APIキーページで完全なキーをコピーし直し、キーが有効になっていることを確認してください |
| model not found                    | モデル名が、選択したグループで実際に利用できるモデルと一致していない            | おすすめモデルから選ぶか、モデル広場で利用可能な一覧を確認してください                |
| リクエストが止まったまま応答しない | アドレスの `/v1` が不足または重複している、あるいは末尾に余分なスラッシュがある | このページの API アドレスどおりに正確に入力してください                               |

## 今すぐ試す
