[Codex CLI](https://github.com/openai/codex) は OpenAI 公式のコマンドライン型プログラミングアシスタントです。環境変数を 2 つ設定するだけで、{{SYSTEM_NAME}} 経由でモデルを呼び出せるようになります。

## 事前準備

[APIキー](/keys) ページでキーを作成してコピーし、Codex CLI 公式の説明に従ってインストールを完了します。

## 設定手順

ターミナルで次の環境変数を設定します（`YOUR_API_KEY` はあなたのキーに置き換えてください）。

macOS / Linux：

```bash
export OPENAI_BASE_URL="{{BASE_URL}}/v1"
export OPENAI_API_KEY="YOUR_API_KEY"
```

Windows PowerShell：

```powershell
$env:OPENAI_BASE_URL = "{{BASE_URL}}/v1"
$env:OPENAI_API_KEY = "YOUR_API_KEY"
```

設定が完了したら、**同じターミナルウィンドウで** Codex CLI を起動してください。

[CC Switch](https://ccswitch.io/zh/) で設定を管理している場合は、APIキー一覧の **⋯** メニューから **CC Switch** を選び、**アプリケーション** を `Codex` にしてワンクリックで取り込むこともできます。アドレスには自動で `/v1` が付きます。

:::tip 設定を永続化する
上記の `export` 文を `~/.bashrc`、`~/.zshrc` などのシェル設定ファイルに書き込み、新しいターミナルを開いてください。
:::

## おすすめモデル

- `gpt-4.1`
- `gpt-4o-mini`

モデル名は、[モデル広場](/pricing) で選択したグループで利用できるモデルに従ってください。

## よくある問題

| 症状                                     | 原因                                                                   | 解決方法                                                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 401                                      | 現在のターミナルで `OPENAI_API_KEY` が設定されていない                 | 同じターミナルウィンドウで設定するか、シェル設定ファイルに書き込んでから新しいターミナルを開いてください   |
| リクエストが OpenAI 公式に送られてしまう | `OPENAI_BASE_URL` が反映されていない、または他の設定で上書きされている | `echo $OPENAI_BASE_URL` を実行して値を確認し、シェルの起動スクリプト内で競合する設定がないか調べてください |
| model not found                          | モデル名が、選択したグループで実際に利用できるモデルと一致していない   | おすすめモデルから選ぶか、モデル広場で利用可能な一覧を確認してください                                     |
